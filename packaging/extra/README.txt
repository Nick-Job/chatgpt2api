ChatGPT2API 桌面版（Windows）
================================

一、启动
--------------------------------
双击 ChatGPT2API.exe（或桌面快捷方式），程序会：
  1. 启动本地服务（默认 http://127.0.0.1:3000）；
  2. 自动打开浏览器进入 Web 面板。

关闭那个黑色命令行窗口即可停止服务。


二、默认信息
--------------------------------
面板地址：http://127.0.0.1:3000
API  地址：http://127.0.0.1:3000/v1
默认密钥：chatgpt2api

密钥请在 config.json 的 "auth-key" 字段修改，或在 Web 面板的
「设置」页面里修改。对外提供服务前务必改成自己的密钥。


三、文件说明
--------------------------------
config.json   主配置（首次启动自动生成，可随时编辑）
data\         账号、日志、图片等运行数据
web_dist\     Web 面板静态文件
start.bat     普通启动
start-lan.bat 局域网启动（其他设备可通过 http://本机IP:3000 访问）

备份时复制 config.json 和 data 目录即可。


四、常用参数
--------------------------------
ChatGPT2API.exe --port 8080        指定端口
ChatGPT2API.exe --host 0.0.0.0     允许局域网访问（会触发防火墙提示）
ChatGPT2API.exe --no-browser       启动后不自动打开浏览器
ChatGPT2API.exe --help             查看全部参数

也可以用环境变量：CHATGPT2API_PORT、CHATGPT2API_HOST。


五、常见问题
--------------------------------
1) 端口被占用
   程序会自动顺延到 3001、3002……，以窗口里打印的地址为准。

2) 浏览器没有自动打开
   手动访问 http://127.0.0.1:3000 即可。

3) 想换数据目录
   设置环境变量 CHATGPT2API_BASE_DIR 指向目标目录，程序会在该目录
   读取 config.json、写入 data。

4) 升级
   直接运行新版本安装程序覆盖安装，config.json 与 data 不会被删除。


六、卸载
--------------------------------
在「设置 → 应用 → 已安装的应用」中卸载。卸载时会询问是否删除配置和
账号数据，选择“否”即可保留数据。
